Panduan Penggunaan Sistem Magelang Labkes

Sistem Laboratorium Magelang Labkes adalah aplikasi komputer untuk mengelola proses pemeriksaan di laboratorium — mulai dari penerimaan permohonan, pengelolaan sampel, hingga pengeluaran hasil pemeriksaan kepada pelanggan atau pasien.

Panduan ini dirancang untuk semua pengguna, termasuk yang baru pertama kali menggunakan sistem. Setiap langkah dijelaskan secara rinci dan jelas.

Topik yang Tersedia dalam Panduan Ini:

Topik Untuk Siapa
Master Data (Customer, Sample Type, Method, Paket, dll.) Admin / Penanggung Jawab Sistem
Permohonan Uji (Non-Klinik / Kesmas) Petugas Pelayanan / Admin
Permohonan Uji Klinik + Penambahan Parameter Petugas Pelayanan / Admin Klinik
Cara Mengubah Harga (Method, Paket, Parameter Klinik) Admin / Kepala Laboratorium
Input Hasil Pemeriksaan Analis / Petugas Laboratorium
Edit & Hapus Data Admin / Supervisor
Troubleshooting (Cara mengatasi masalah umum) Semua Pengguna

Sebelum Memulai

Syarat Menggunakan Sistem:

  • Sudah memiliki akun dan sudah login ke sistem
  • Akun Anda memiliki hak akses ke menu yang ingin digunakan (jika menu tidak muncul, hubungi admin)
  • Data-data dasar (master data) sudah disiapkan oleh admin

Cara Login ke Sistem:

  1. Buka browser (Chrome, Firefox, atau Edge)
  2. Ketik alamat sistem di kotak alamat browser — tanyakan ke admin jika belum tahu alamatnya
  3. Masukkan Username dan Password Anda
  4. Klik tombol Login atau tekan Enter
  5. Jika berhasil, halaman utama sistem akan terbuka

Mengenal Tampilan Utama Sistem:

Bagian Layar Fungsinya
Sidebar (sebelah kiri) Daftar menu utama sistem. Klik menu untuk membuka halaman yang diinginkan.
Area Konten (tengah) Tempat data dan form ditampilkan.
Header (atas) Menampilkan nama pengguna yang login dan tombol logout.

✅ Tips Penting: Selalu klik tombol Simpan setelah mengisi form. Jika berpindah halaman sebelum menyimpan, data yang sudah diisi akan hilang.

Membuat Permohonan Uji

Screenshot: Form Tambah Permohonan Uji

Tambahkan screenshot form tambah Permohonan Uji di sini

Permohonan Uji adalah proses awal untuk pemeriksaan non-klinik (kesmas).

Langkah-langkah:

  1. Akses Menu Permohonan Uji
    • Klik menu Permohonan Uji di sidebar
    • Klik tombol Tambah Permohonan Uji Baru
  2. Isi Data Dasar Permohonan
    • Tanggal Permohonan (otomatis, dapat diubah)
    • Customer (wajib)
      • Pilih customer dari daftar, atau
      • Klik "Tambah Customer Baru" untuk menambah customer baru
    • Nama Personil (wajib) - Nama petugas yang menangani permohonan
  3. Pengaturan Sample
    • Mode Pengiriman Sample:
      • Sample Dibawa Sendiri (pengambil_sample = 0)
        • Isi Tanggal Penerimaan Sample
        • Isi Kondisi Sample (Baik/Rusak/Lainnya)
        • Jika kondisi "Lainnya", isi keterangan
      • Sample Diambil Lab (pengambil_sample = 1)
        • Isi Tanggal Sampling
        • Isi Paket Sampling (opsional)
  4. Informasi Pembayaran
    • Total Harga (akan dihitung otomatis setelah menambah sample)
    • Uang Muka (wajib)
    • Kekurangan Pembayaran (otomatis)
    • Status Pembayaran (Lunas/Belum Lunas)
  5. Simpan Permohonan Uji
    • Klik tombol Simpan
    • Sistem akan generate Kode Permohonan Uji dengan format: PU.NK/YYYYMMDD/XXXX
    • Setelah disimpan, akan redirect ke halaman detail permohonan uji

Informasi Penting

  • Kode Permohonan Uji dibuat otomatis dengan format: PU.NK/[TANGGAL]/[URUTAN]
  • Setelah permohonan uji dibuat, status awal adalah REGISTER
  • Permohonan uji harus memiliki minimal 1 sample untuk dapat diproses
  • Total harga akan dihitung dari jumlah sample dan method yang dipilih

Menambahkan Sample

Screenshot: Form Tambah Sample

Tambahkan screenshot form tambah Sample di sini

Setelah Permohonan Uji dibuat, langkah selanjutnya adalah menambahkan sample ke dalam permohonan uji tersebut.

Langkah-langkah:

  1. Akses Halaman Tambah Sample
    • Dari halaman detail Permohonan Uji, klik tombol Tambah Sample
    • Atau akses langsung melalui menu Sample > Tambah Sample Baru
  2. Pilih Jenis Sample
    • Pilih Sample Type dari daftar
    • Setiap sample type memiliki method yang tersedia
  3. Pilih Metode Pemeriksaan

    Ada dua cara untuk memilih metode:

    A. Menggunakan Paket

    • Pilih Packet yang sesuai dengan sample type
    • Sistem akan otomatis memilih semua method dalam packet
    • Dapat menambah method tambahan di luar packet

    B. Memilih Method Individual

    • Pilih method satu per satu dari daftar
    • Method dikelompokkan berdasarkan laboratorium
    • Dapat memilih method dari beberapa laboratorium sekaligus
  4. Informasi Sample
    • Titik Pengambilan (opsional) - Lokasi pengambilan sample
    • Tanggal Sampling (wajib) - Tanggal dan waktu pengambilan sample
    • Tanggal Pengiriman (opsional) - Tanggal sample dikirim ke lab
    • Catatan Sample (opsional) - Keterangan tambahan tentang sample
  5. Informasi Biaya
    • Biaya Sample (otomatis dihitung)
      • Jika menggunakan packet: harga packet + method tambahan
      • Jika individual: total harga semua method
    • Biaya Sampling (jika sample diambil lab)
      • Default: Rp 20.000
      • Dapat disesuaikan
  6. Simpan Sample
    • Klik tombol Simpan
    • Sistem akan:
      • Generate kode sample untuk setiap laboratorium
      • Membuat record sample untuk setiap laboratorium yang memiliki method
      • Menghitung total biaya

Penerimaan Sample

Screenshot: Form Penerimaan Sample

Tambahkan screenshot form penerimaan Sample di sini

Setelah sample ditambahkan, sample perlu diterima di laboratorium.

Langkah-langkah:

  1. Akses Halaman Penerimaan Sample
    • Dari halaman detail sample, klik Terima Sample
    • Atau akses melalui menu Penerimaan Sample
  2. Isi Data Penerimaan
    • Wadah (wajib) - Pilih jenis wadah dari daftar, atau isi "Lainnya" jika tidak ada di daftar
    • Pengawet (wajib) - Jenis pengawet yang digunakan
    • Volume (wajib) - Volume sample dalam wadah
    • Unit (wajib) - Satuan volume (mL, L, dll)
    • Kondisi Sample (wajib) - Baik/Rusak/Tidak Sesuai
    • Validasi Sample (wajib) - Layak/Tidak Layak untuk diperiksa
  3. Simpan Penerimaan
    • Klik tombol Simpan
    • Sample akan berstatus DITERIMA dan siap untuk pemeriksaan

Catatan Penting tentang Sample

Satu Permohonan Bisa Banyak Sample:

  • Satu permohonan uji bisa memiliki banyak titik pengambilan sample — setiap titik adalah sample yang berbeda
  • Contoh: 5 titik sumur berbeda = 5 sample dalam 1 permohonan uji

Kode Sample:

  • Format: S.[LAB_CODE]-[TANGGAL]-[URUTAN]
  • Contoh: S.KMA-20240115-0001
  • Setiap laboratorium memiliki kode sample sendiri

Biaya:

  • Biaya sample dihitung per laboratorium
  • Jika sample memiliki method dari 2 laboratorium, akan dibuat 2 sample dengan biaya terpisah

Gambaran Alur Verifikasi Kesmas (Non-Klinik)

Setelah sample ditambahkan ke permohonan uji, proses verifikasi dilakukan secara berurutan. Setiap step harus diselesaikan sebelum bisa lanjut ke step berikutnya. Semua step bisa dipantau dari halaman Verifikasi Sample (klik tombol "Verifikasi" di halaman detail sample).

Tiga Fase Besar Verifikasi:

🔵 Pra-Analitik 🟢 Analitik 🟣 Pasca-Analitik
  1. Permintaan Pemeriksaan (otomatis)
  2. Persiapan Sampel (otomatis)
  3. Pengambilan Sampel (otomatis)
  4. Penerimaan Sampel ← diisi petugas
  5. Penanganan Sampel ← diisi petugas
  1. Langkah-langkah Analitik (sesuai lab)
  2. Baca Hasil ← analis
  3. Pengetikan Hasil ← analis
  1. Pelaporan Hasil ← admin/kepala
  2. Verifikasi Hasil ← kepala lab
  3. Pengesahan Hasil ← pejabat berwenang
  4. Cetak LHU ← admin

Cara Membuka Halaman Verifikasi:

  1. Dari menu Permohonan Uji atau menu Sample, cari data permohonan/sample yang bersangkutan
  2. Buka halaman detail sample
  3. Klik tombol "Verifikasi" atau "Proses Verifikasi"
  4. Halaman verifikasi akan menampilkan semua step beserta statusnya

✅ Tips: Step yang sudah selesai akan menampilkan tanggal di kolomnya. Step yang belum selesai menampilkan tombol "Selesai" atau form isian.

Step 1 (Pra-Analitik): Penerimaan Sample

Penerimaan Sample adalah proses menerima dan mencatat kondisi sample yang masuk ke laboratorium. Ini adalah langkah pertama yang harus dilakukan petugas penerimaan setelah sample tiba di lab.

Langkah-langkah:

  1. Buka Halaman Verifikasi Sample
    • Dari menu Sample atau Permohonan Uji, buka detail sample yang akan diterima
    • Klik tombol "Verifikasi"
    • Di kolom Pra-Analitik, cari baris "Penerimaan Sampel"
    • Klik tombol "Selesai" di baris tersebut
  2. Isi Form Penerimaan Sample
    Kolom Penjelasan Wajib? Contoh Isi
    Wadah Jenis wadah tempat sample disimpan. Pilih dari daftar, atau pilih "Lainnya" jika tidak ada. Ya Botol Plastik, Botol Kaca, Galon
    Keterangan Wadah Lain Isi jika pilihan wadah = "Lainnya" Jika Lainnya Jerigen 5 liter
    Pengawet Jenis bahan pengawet yang digunakan (jika ada) Ya H2SO4, Na2S2O3, Tanpa Pengawet
    Volume Jumlah/volume sample yang diterima Ya 500
    Unit/Satuan Satuan untuk volume di atas Ya mL, L, gram
    Kondisi Sample Kondisi fisik sample saat diterima Ya Baik / Rusak / Tidak Sesuai
    Validasi Sample Apakah sample layak untuk diperiksa? Ya Layak / Tidak Layak
  3. Simpan Penerimaan
    • Klik tombol Simpan
    • Sistem akan mencatat tanggal penerimaan secara otomatis
    • Halaman kembali ke verifikasi — baris "Penerimaan Sampel" akan menampilkan tanggal

⚠️ Penting: Jika sample dinilai Tidak Layak, tetap simpan data penerimaannya dan segera informasikan ke customer/pelanggan bahwa sample perlu diambil ulang.

Step 2 (Pra-Analitik): Penanganan Sample

Penanganan Sample adalah proses pencatatan bahwa sample telah ditangani dan disiapkan untuk pemeriksaan analitik. Step ini dilakukan setelah Penerimaan Sample selesai.

Langkah-langkah:

  1. Di halaman Verifikasi, cari baris "Penanganan Sampel" di kolom Pra-Analitik
  2. Klik tombol "Selesai" di baris tersebut (hanya muncul jika Penerimaan Sample sudah dilakukan)
  3. Sistem akan mencatat tanggal penanganan secara otomatis
  4. Jika perlu mengubah tanggal, klik ikon pensil ✏️ di sebelah tanggal yang sudah tercatat

💡 Catatan: Penanganan Sample bisa diedit kemudian jika ada perubahan. Klik ikon pensil untuk membuka form edit dan ubah tanggalnya.

Step 3 (Analitik): Pemeriksaan Laboratorium

Fase Analitik adalah tahap pemeriksaan sesungguhnya yang dilakukan oleh analis laboratorium. Langkah-langkah analitik berbeda-beda tergantung jenis laboratorium (Kimia atau Mikrobiologi) dan jenis pemeriksaan.

Langkah Analitik Umum (muncul di halaman Verifikasi, kolom "Analitik"):

  1. Langkah-langkah Pemeriksaan Bertahap
    • Di halaman Verifikasi, kolom Analitik menampilkan daftar tahapan pemeriksaan sesuai metode laboratorium
    • Setiap tahapan memiliki field tanggal yang perlu diisi
    • Isi tanggal setiap tahapan setelah kegiatan fisiknya selesai dilakukan
    • Klik tombol ✓ (centang/Submit) untuk menyimpan tanggal setiap tahap
  2. Baca Hasil (Analitik)
    • Setelah semua tahapan selesai, langkah berikutnya adalah Baca Hasil
    • Klik tombol "Baca Hasil" atau link yang muncul di baris tersebut
    • Analis memasukkan nilai hasil pengukuran untuk setiap parameter
    • Sistem akan membandingkan hasil dengan Baku Mutu — nilai yang melebihi batas akan ditandai merah
    • Setelah semua nilai diisi, klik Simpan

⚠️ Perhatian: Nilai hasil yang berwarna merah pada halaman baca hasil berarti nilainya melebihi batas baku mutu yang sudah ditetapkan. Ini akan muncul di laporan hasil sebagai "tidak memenuhi syarat".

Step 4 (Analitik): Pengetikan Hasil

Pengetikan Hasil adalah proses memasukkan hasil pemeriksaan secara resmi ke sistem untuk keperluan laporan. Berbeda dengan "Baca Hasil" yang mencatat nilai mentah, Pengetikan Hasil memastikan data siap untuk diterbitkan.

Langkah-langkah:

  1. Di halaman Verifikasi, pada kolom Analitik, klik link atau tombol "Pengetikan Hasil"
  2. Halaman pengetikan hasil akan terbuka, menampilkan daftar parameter beserta nilai yang sudah dibaca
  3. Periksa kembali setiap nilai hasil:
    • Nilai hasil yang melebihi baku mutu akan ditandai merah
    • Isi kolom Satuan jika belum terisi
    • Isi kolom Keterangan jika diperlukan (contoh: "Tidak Memenuhi Syarat")
  4. Isi Tanggal Pengetikan
  5. Klik tombol Simpan
  6. Sistem kembali ke halaman verifikasi — baris Pengetikan Hasil menampilkan tanggal

Step 5 (Pasca-Analitik): Pelaporan Hasil

Pelaporan Hasil adalah proses pencatatan tanggal pelaporan resmi hasil pemeriksaan. Step ini menandai bahwa hasil sudah siap dilaporkan secara resmi.

Langkah-langkah:

  1. Di halaman Verifikasi, kolom Pasca-Analitik, cari baris "Pelaporan Hasil"
  2. Isi kolom Tanggal Pelaporan dengan tanggal yang sesuai
  3. Klik tombol ✓ (centang/Submit)
  4. Baris Pelaporan Hasil akan menampilkan tanggal yang sudah diisi

💡 Catatan: Tanggal pelaporan hasil ini akan muncul di dokumen LHU (Laporan Hasil Uji) yang dicetak untuk pelanggan.

Step 6 (Pasca-Analitik): Verifikasi Hasil

Verifikasi Hasil (Step/Activity 4) adalah proses review dan persetujuan hasil pemeriksaan oleh Kepala Laboratorium atau petugas yang ditunjuk. Ini memastikan hasil sudah benar sebelum disahkan.

🔐 Hak Akses: Langkah ini biasanya hanya bisa dilakukan oleh Kepala Laboratorium atau supervisor yang memiliki akses verifikasi.

Apa yang Diisi di Form Verifikasi Hasil:

Kolom Penjelasan
Tanggal Mulai Verifikasi Tanggal dimulainya proses verifikasi oleh kepala laboratorium
Tanggal Selesai Verifikasi Tanggal selesainya verifikasi
Nama Petugas Verifikasi Nama kepala lab atau petugas yang melakukan verifikasi. Bisa dipilih dari daftar atau diisi manual.
Hasil Pemeriksaan (review) Petugas memeriksa ulang semua nilai hasil — nilai merah = tidak memenuhi baku mutu perlu diperhatikan

Langkah-langkah:

  1. Di halaman Verifikasi, klik link "Verifikasi Hasil" di kolom Pasca-Analitik
  2. Form verifikasi akan terbuka — tampilkan semua hasil pemeriksaan untuk diperiksa ulang
  3. Periksa setiap nilai hasil dengan teliti
  4. Isi Tanggal Mulai dan Tanggal Selesai verifikasi
  5. Pilih atau isi Nama Petugas yang melakukan verifikasi
  6. Klik tombol Simpan

Apa itu Baku Mutu?

Baku Mutu adalah nilai standar/ambang batas yang ditetapkan oleh peraturan atau referensi ilmiah sebagai batas maksimum atau minimum yang diperbolehkan untuk setiap parameter uji.

Contoh: Parameter "Coliform" pada Air Minum memiliki baku mutu 0 CFU/100 mL — artinya tidak boleh ada bakteri Coliform sama sekali. Jika hasil pemeriksaan menunjukkan nilai di atas baku mutu, sistem akan menandainya dengan warna merah di laporan.

Jenis Baku Mutu di Sistem:

Jenis Menu di Sistem Keterangan
Baku Mutu Kimia Master Data → Baku Mutu Kimia Untuk parameter-parameter pengujian Kimia (logam berat, pH, turbiditas, dll.)
Baku Mutu Mikrobiologi Master Data → Baku Mutu Mikrobiologi Untuk parameter-parameter pengujian Mikrobiologi (Coliform, E.coli, dll.)
Baku Mutu Klinik Master Data → Baku Mutu Klinik Nilai normal untuk pemeriksaan klinik (lihat bagian sebelumnya)

Apa itu Parameter Pemeriksaan?
Parameter adalah jenis-jenis tes yang akan dilakukan pada pasien. Contoh: Gula Darah, Kolesterol, Hemoglobin, Urine Lengkap, dan sebagainya. Setiap parameter memiliki harga sendiri. Anda harus menambahkan parameter sebelum pemeriksaan dapat dilanjutkan.

⚠️ Perhatian: Pastikan Permohonan Uji Klinik sudah dibuat terlebih dahulu (lihat langkah sebelumnya). Parameter baru bisa ditambahkan setelah permohonan tersimpan dan statusnya PARAMETER.

Langkah-langkah Menambah Parameter:

  1. Buka daftar Permohonan Uji Klinik
    • Klik menu Permohonan Uji Klinik di sebelah kiri layar (sidebar)
    • Cari nama pasien yang ingin ditambahkan parameternya
    • Klik pada baris data pasien tersebut untuk membuka detailnya
  2. Buka Halaman Parameter
    • Di halaman detail pasien, cari tombol berwarna "Tambah Parameter" atau "+ Parameter"
    • Klik tombol tersebut — halaman form penambahan parameter akan terbuka
  3. Pilih Cara Penambahan Parameter

    Ada dua cara menambahkan parameter:

    Cara Keterangan Kapan Digunakan
    A. Paket Memilih satu paket yang sudah berisi beberapa parameter sekaligus Jika ada paket yang sesuai (lebih hemat dan cepat)
    B. Individual Memilih parameter satu per satu sesuai kebutuhan Jika tidak ada paket yang cocok atau hanya butuh 1-2 tes tertentu
  4. Cara A — Memilih Parameter dengan Paket
    1. Pada kolom atau dropdown "Tipe Parameter", pilih P (Paket)
    2. Pada dropdown "Jenis Parameter / Nama Paket", klik dan pilih nama paket yang sesuai (contoh: "Paket Darah Lengkap", "Paket Profil Lipid")

    4. Jika paket menggunakan satuan (misal: satuan botol/tabung), pilih pada dropdown "Satuan"
    5. Klik tombol Simpan / Tambahkan
    6. Ulangi untuk menambah paket lain jika diperlukan
  5. Cara B — Memilih Parameter Individual
    1. Pada kolom atau dropdown "Tipe Parameter", pilih I (Individual)
    2. Pada dropdown "Jenis Parameter", klik dan cari nama tes yang diinginkan (contoh: "Gula Darah Puasa", "Kolesterol Total", "Hemoglobin")
    3. Setelah memilih, harga akan muncul otomatis di kolom "Harga"
    4. Klik tombol Tambahkan atau + (plus) untuk menambahkan parameter tersebut ke daftar
    5. Ulangi langkah b–d untuk setiap parameter yang ingin ditambahkan
    6. Setelah semua parameter dipilih, klik tombol Simpan
  6. Periksa Ringkasan Harga
    • Setelah menyimpan, sistem akan menampilkan daftar parameter yang sudah ditambahkan beserta harga masing-masing
    • Periksa apakah semua parameter sudah benar dan harga total sudah sesuai
    • Jika ada yang salah, lihat panduan Hapus / Ubah Parameter
  7. Status Berubah Otomatis
    • Setelah parameter ditambahkan, status permohonan akan berubah dari PARAMETER menjadi ANALIS

Cara Mengubah Harga Method (Parameter Non-Klinik)

Apa itu Method?
Method adalah jenis pengujian laboratorium non-klinik seperti pengujian air, makanan, udara, dll. Setiap method memiliki harga yang bisa diubah kapan saja oleh admin/petugas yang berwenang.

⚠️ Perhatian: Perubahan harga method tidak akan mempengaruhi permohonan uji yang sudah ada. Harga baru hanya berlaku untuk permohonan uji yang dibuat setelah perubahan tersimpan.

Langkah-langkah Mengubah Harga Method:

  1. Masuk ke Menu Method
    • Di sidebar sebelah kiri, klik menu Master Data
    • Kemudian klik submenu Method
    • Akan muncul daftar semua method yang tersedia
  2. Cari Method yang Ingin Diubah Harganya
    • Gunakan kotak pencarian di bagian atas tabel untuk mencari nama method
    • Ketik sebagian nama method, lalu tekan Enter atau tunggu hingga daftar tersaring
  3. Buka Form Edit Method
    • Di baris method yang ingin diubah, klik tombol Edit (ikon pensil ✏️ atau tulisan "Edit")
    • Form edit akan terbuka
  4. Ubah Harga

    Di form edit, cari dan ubah kolom-kolom harga berikut:

    Kolom Keterangan Wajib?
    Harga Bahan Biaya bahan-bahan yang digunakan dalam pengujian Opsional
    Harga Sarana Biaya penggunaan alat/sarana laboratorium Opsional
    Harga Jasa Biaya jasa petugas yang melakukan pengujian Opsional
    Harga Total Method Total harga yang ditagihkan ke pelanggan. Ini yang paling penting diubah. Wajib
    • Klik pada kolom Harga Total Method, hapus angka lama, lalu ketik angka baru
    • Contoh: Ubah dari 50000 menjadi 75000 (tanpa titik atau koma)
  5. Simpan Perubahan
    • Klik tombol Simpan atau Update
    • Jika berhasil, akan muncul pesan "Data berhasil diperbarui"
    • Harga baru sudah aktif untuk permohonan berikutnya

💡 Tips: Jika ada banyak method yang perlu diubah harganya, lakukan satu per satu dan catat method-method yang sudah diubah agar tidak terlewat.

Cara Mengubah Harga Paket Pemeriksaan (Packet)

Apa itu Paket?
Paket adalah kumpulan beberapa method yang dijual sebagai satu kesatuan dengan harga yang biasanya lebih terjangkau. Contoh: "Paket Air Minum Lengkap" berisi 20 pengujian dengan satu harga.

⚠️ Perhatian: Mengubah harga paket tidak secara otomatis mengubah harga method di dalamnya. Harga paket adalah harga jual keseluruhan paket tersebut.

Langkah-langkah Mengubah Harga Paket:

  1. Masuk ke Menu Packet
    • Di sidebar sebelah kiri, klik menu Master Data
    • Kemudian klik submenu Packet
    • Daftar semua paket akan ditampilkan
  2. Cari Paket yang Ingin Diubah
    • Gunakan kotak pencarian untuk mengetik nama paket
    • Atau cari secara manual di daftar paket
  3. Buka Form Edit Paket
    • Klik tombol Edit (ikon pensil ✏️) di baris paket yang bersangkutan
  4. Ubah Harga Paket
    • Cari kolom "Harga Packet"
    • Klik kolom tersebut, hapus angka lama
    • Ketik harga baru (contoh: 300000)
    • Pastikan angka tidak menggunakan titik pemisah ribuan — tulis angka langsung
  5. Simpan Perubahan
    • Klik tombol Simpan atau Update
    • Muncul pesan sukses berarti harga paket sudah berubah

  5. Klik tombol Simpan Paket

Baku Mutu / Nilai Normal Parameter

Baku Mutu (untuk non-klinik) atau Nilai Normal (untuk klinik) adalah rentang nilai yang dianggap normal atau memenuhi standar. Sistem menggunakannya untuk memberi tanda peringatan jika hasil pemeriksaan di luar rentang normal.

Cara Mengatur Nilai Normal untuk Parameter Klinik:

  1. Buka menu Jenis Parameter Klinik
  2. Klik Edit pada parameter yang ingin diatur nilai normalnya
  3. Isi kolom:
    • Nilai Normal Min — batas bawah (contoh: 70 untuk gula darah puasa)
    • Nilai Normal Max — batas atas (contoh: 100)
    • Jika nilai normal berbeda berdasarkan jenis kelamin, isi kolom terpisah untuk Laki-laki dan Perempuan jika tersedia
  4. Klik Simpan

💡 Tips: Nilai normal yang sudah diatur akan otomatis memberi warna merah pada hasil pemeriksaan yang di luar rentang tersebut, sehingga dokter lebih mudah melihat hasil yang tidak normal.

Cara Mengedit (Mengubah) Data

Hampir semua data di sistem ini bisa diubah/diedit, termasuk data customer, jenis sample, method, paket, dan lainnya. Berikut cara umum mengedit data.

Cara Umum Mengedit Data:

  1. Buka menu yang berisi data yang ingin diedit (contoh: menu Customer)
  2. Akan muncul daftar/tabel data
  3. Cari baris data yang ingin diubah menggunakan kotak pencarian atau scroll
  4. Klik tombol Edit (ikon pensil ✏️ atau tulisan "Edit") di baris tersebut
  5. Form edit akan terbuka — ubah kolom yang perlu diubah
  6. Klik tombol Simpan / Update / Perbarui
  7. Jika berhasil, akan muncul notifikasi hijau "Data berhasil diperbarui"

⚠️ Perhatian saat mengedit:

  • Jangan mengubah kode unik (seperti kode customer, kode method) jika data tersebut sudah digunakan di permohonan uji. Hal ini bisa menyebabkan data tidak konsisten.
  • Perubahan harga hanya berlaku untuk transaksi baru, bukan transaksi yang sudah ada.

Cara Edit Permohonan Uji yang Sudah Dibuat:

  1. Buka menu Permohonan Uji
  2. Cari nomor permohonan yang ingin diedit
  3. Klik pada baris untuk membuka halaman detail
  4. Di halaman detail, klik tombol Edit
  5. Ubah data yang diperlukan (misal: uang muka, status pembayaran, catatan)
  6. Klik Simpan

🚫 Tidak bisa diubah: Nomor/kode permohonan yang sudah tercetak atau sudah dilaporkan ke instansi resmi tidak boleh diubah. Hubungi admin sistem jika ada kekeliruan.

Cara Menghapus Data

Data yang dihapus tidak benar-benar hilang permanen — sistem menggunakan "soft delete" yang menyembunyikan data dari daftar aktif. Admin dapat memulihkan data yang terhapus jika diperlukan.

🚫 Perhatian Penting:

  • Jangan hapus data master (method, customer, dll.) yang sudah digunakan dalam permohonan uji aktif.
  • Jangan hapus parameter klinik yang sudah ada hasil pemeriksaannya.
  • Jika ragu, tanyakan ke admin sistem terlebih dahulu.

Cara Umum Menghapus Data:

  1. Buka menu yang berisi data yang ingin dihapus
  2. Cari baris data yang ingin dihapus
  3. Klik tombol Hapus (ikon tempat sampah 🗑️ atau tulisan "Hapus")
  4. Akan muncul kotak konfirmasi — baca pesannya dengan teliti
  5. Klik Ya, Hapus atau Konfirmasi jika yakin ingin menghapus
  6. Klik Batal jika tidak jadi menghapus
  7. Jika berhasil, data akan hilang dari daftar (tapi masih bisa dipulihkan oleh admin)

Tips: Pengelolaan Master Data

  • Periksa sebelum menyimpan — Baca ulang semua isian sebelum klik Simpan, terutama nama dan kode yang harus unik.
  • Jangan duplikasi kode — Kode seperti kode customer, kode method, kode paket harus unik. Jika ada error "kode sudah digunakan", gunakan kode yang berbeda.
  • Atur harga dengan cermat — Perubahan harga method atau paket hanya berlaku untuk permohonan baru. Koordinasikan dengan kepala laboratorium sebelum mengubah harga.
  • Jangan hapus sembarangan — Data yang dihapus dapat mempengaruhi permohonan yang sudah ada. Jika ragu, nonaktifkan dulu daripada menghapus.
  • Backup berkala — Pastikan admin IT melakukan backup database secara rutin (minimal seminggu sekali).

Tips: Permohonan Uji (Non-Klinik)

  • Verifikasi data customer — Sebelum menyimpan permohonan, pastikan nama customer, alamat, dan kontak sudah benar.
  • Simpan dulu, tambah sample kemudian — Permohonan harus disimpan terlebih dahulu sebelum bisa menambahkan sample.
  • Catat kondisi sample — Jika sample datang dalam kondisi tidak baik (rusak, bocor, tidak sesuai standar), catat di kolom kondisi sample. Ini penting untuk keperluan dokumentasi.
  • Total harga otomatis — Jangan ubah total harga secara manual kecuali ada alasan khusus. Biarkan sistem menghitungnya dari method/paket yang dipilih.
  • Update status pembayaran — Jika pelanggan sudah melunasi, segera update status pembayaran menjadi "Lunas".

Tips: Pengelolaan Sample

  • Labeling yang jelas — Pastikan setiap sample yang diterima sudah diberi label dengan nomor sampel yang sesuai dengan yang ada di sistem.
  • Catat kondisi saat penerimaan — Jika sample tidak dalam kondisi ideal, catat di kolom kondisi sample agar ada dokumentasi tertulis.
  • Konfirmasi laboratorium — Pastikan sample sudah diterima dan dikonfirmasi oleh laboratorium yang bersangkutan sebelum pemeriksaan dimulai.
  • Satu permohonan bisa banyak sample — Sebuah permohonan uji bisa memiliki banyak titik pengambilan sample. Setiap titik pengambilan adalah sample yang berbeda.

Tips: Permohonan Uji Klinik

  • Data pasien harus akurat — Nama, tanggal lahir, dan jenis kelamin pasien harus benar karena berpengaruh pada nilai normal hasil pemeriksaan.
  • Pilih parameter sesuai kebutuhan — Jangan memilih parameter yang tidak diperlukan. Koordinasikan dengan dokter/petugas medis sebelum memilih parameter.
  • Periksa harga sebelum menyimpan — Setelah memilih parameter, periksa total harga yang muncul sebelum menyimpan permohonan.
  • Parameter bisa ditambah setelah permohonan dibuat — Jika ada parameter yang perlu ditambahkan setelah permohonan disimpan, buka halaman detail dan klik "Tambah Parameter" (selama status masih ANALIS).
  • Privasi data pasien — Jangan memberikan data atau hasil pemeriksaan pasien kepada pihak yang tidak berwenang. Patuhi aturan privasi data kesehatan.
  • Jangan lewatkan verifikasi — Hasil pemeriksaan harus diverifikasi oleh dokter atau kepala laboratorium sebelum bisa diserahkan ke pasien.

Masalah yang Terjadi Kemungkinan Penyebab & Solusinya
Tidak bisa login / username atau password salah
  • Pastikan Caps Lock tidak aktif — password bersifat huruf besar/kecil
  • Coba ketik ulang username dan password dengan hati-hati
  • Jika lupa password, hubungi admin sistem untuk reset password
Menu tidak muncul / tidak bisa diakses
  • Akun Anda mungkin tidak memiliki izin untuk menu tersebut
  • Hubungi admin untuk meminta akses ke menu yang diperlukan
  • Coba logout kemudian login kembali
Customer tidak muncul di daftar dropdown
  • Customer mungkin belum ditambahkan ke sistem → Tambahkan terlebih dahulu di menu Customer
  • Customer mungkin sudah dihapus → Minta admin memulihkan data customer
  • Coba ketik nama customer di kotak pencarian dropdown
Method / Parameter tidak muncul saat memilih jenis sample
  • Method belum dikaitkan dengan jenis sample tersebut → Hubungi admin untuk mengatur relasi method-sample type
  • Method mungkin dinonaktifkan → Hubungi admin untuk mengaktifkan kembali
  • Method belum dikaitkan dengan laboratorium → Admin perlu mengecek data method

  • Ada kolom wajib yang belum diisi — perhatikan kolom yang berwarna merah atau bertanda bintang (*)

  • Baca pesan merah yang muncul untuk mengetahui kolom mana yang bermasalah

  • Status permohonan mungkin sudah bukan PARAMETER atau ANALIS — cek status di halaman detail
  • Akun tidak punya hak akses → Hubungi admin
  • Coba refresh halaman (tekan F5)

  • Pastikan tombol Simpan sudah diklik dan muncul notifikasi sukses
  • Refresh halaman untuk melihat harga terbaru
  • Perubahan harga tidak berlaku mundur — hanya berlaku untuk transaksi baru
Halaman loading terlalu lama / tidak terbuka
  • Periksa koneksi internet Anda
  • Coba refresh halaman (tekan F5 atau tombol refresh browser)
  • Coba logout kemudian login kembali
  • Jika masalah berlanjut, hubungi admin/IT
Data yang dihapus ingin dikembalikan
  • Segera hubungi admin sistem — data yang dihapus biasanya masih bisa dipulihkan
  • Sampaikan nama data yang terhapus dan kapan terhapusnya
Hasil cetak / print tidak sesuai
  • Pastikan semua data sudah diisi dengan benar sebelum mencetak
  • Cek pengaturan printer (kertas, orientasi)
  • Gunakan fitur "Print Preview" sebelum mencetak
  • Hubungi admin jika format cetak tidak sesuai standar
