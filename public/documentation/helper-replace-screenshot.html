🔧 Helper: Ganti Placeholder dengan Screenshot

📸 Step 1: Upload Screenshot

Upload screenshot ke folder screenshots/

Contoh nama file: customer-list.png

✂️ Step 2: Cari Placeholder di index.html

Buka file index.html dan cari placeholder yang ingin diganti

Contoh placeholder:

<div class="screenshot-container"> <div class="screenshot-placeholder"> <i class="fas fa-image"></i> <p>Screenshot: Menu Customer</p> <small>Tambahkan screenshot halaman Customer di sini</small> </div> </div>

🔄 Step 3: Ganti dengan Tag IMG

Ganti seluruh placeholder dengan tag <img>

❌ SEBELUM (Placeholder)

<div class="screenshot-container"> <div class="screenshot-placeholder"> <i class="fas fa-image"></i> <p>Screenshot: Menu Customer</p> <small>Tambahkan screenshot...</small> </div> </div>

✅ SESUDAH (Dengan Screenshot)

<div class="screenshot-container"> <img src="screenshots/customer-list.png" alt="Halaman Daftar Customer" /> </div>

📝 Step 4: Template Kode untuk Copy-Paste

Copy kode di bawah ini dan sesuaikan:

<div class="screenshot-container"> <img src="screenshots/NAMA_FILE.png" alt="DESKRIPSI SCREENSHOT" /> </div>
Catatan:
  • Ganti NAMA_FILE.png dengan nama file screenshot yang sudah diupload
  • Ganti DESKRIPSI SCREENSHOT dengan deskripsi yang jelas
  • Path relatif dari index.html, jadi gunakan screenshots/ bukan /screenshots/

📋 Contoh Lengkap: Customer Section

Lokasi di index.html: Section master-data-customer (sekitar line 179-185)

Kode Lengkap Setelah Diganti:

<section id="master-data-customer" class="doc-section"> <div class="section-header"> <h1>Customer (Pelanggan)</h1> </div> <div class="section-content"> <!-- Screenshot Halaman List Customer --> <div class="screenshot-container"> <img src="screenshots/customer-list.png" alt="Halaman Daftar Customer" /> </div> <!-- Screenshot Form Tambah Customer (opsional) --> <div class="screenshot-container"> <img src="screenshots/customer-form.png" alt="Form Tambah Customer" /> </div> <div class="info-box"> <p><strong>Fungsi:</strong> Mengelola data pelanggan...</p> </div> ... </div> </section>

✅ Step 5: Test Screenshot

  1. Simpan file index.html
  2. Buka di browser: http://localhost:8000/documentation/index.html
  3. Scroll ke section yang sudah diupdate
  4. Pastikan screenshot muncul
  5. Klik screenshot untuk test modal zoom
💡 Tips:
  • Gunakan nama file yang jelas: customer-list.png bukan screenshot.png
  • Alt text harus deskriptif untuk aksesibilitas
  • Jika screenshot tidak muncul, cek path dan nama file (case-sensitive di Linux)
  • Kompres screenshot jika terlalu besar (>500KB)
